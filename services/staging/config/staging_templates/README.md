# OGC API - Processes schemas

The YAML files of this folder are the [OGC API - Processes](https://ogcapi.ogc.org/processes/) OpenAPI schemas. They
are used to validate the format of the inputs and outputs of the endpoints of the staging service.

They come from the [ogcapi-processes](https://github.com/opengeospatial/ogcapi-processes/tree/1.0-draft.6.metanorma/core/openapi/schemas)
repository of the OGC. Examples of valid data for each endpoint are given in the
[OGC API - Processes documentation](https://developer.ogc.org/api/processes/index.html).

**Caution:** these schemas are regularly updated by the OGC: check the
[ogcapi-processes](https://github.com/opengeospatial/ogcapi-processes) repository for new versions.
