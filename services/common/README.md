# rs-server-common

Code shared by the rs-server services: authentication, STAC API common implementation, OData to STAC mapping, S3 access, logging and OpenTelemetry instrumentation.

This package is part of [rs-server](https://github.com/RS-PYTHON/rs-server), see its
